# Dangerous Excel Shortcuts

The Excel shortcuts nobody teaches you — because most of them look completely harmless right up until they silently change way more than the cell you were looking at. Windows and Mac key combos side by side.

The fourth domain built on the [same pipeline](https://github.com/rblake2320/windows-cli-security-arsenal) as the CLI/WinGet/shell tools — this one deliberately reference-only, since a keyboard shortcut only means something inside a specific focused application, not something you can safely "run" from an external panel. No desktop app, no Run button, no MCP server: just a fast, searchable reference.

**[View the live page →](https://rblake2320.github.io/dangerous-excel-shortcuts/)**

## What's inside

34 shortcuts across 9 categories: Selection Traps, Filtered & Visible-Only, Repeat & Redo, Recalculation & Auditing, Flash Fill & AutoFill, Data Destruction Risks, Navigation Power Moves, Paste Special, Workbook-Wide Risks.

Every entry tagged safe, power move, or dangerous, with the "why it's dangerous" reasoning spelled out — not just the key combo.

## Usage

Open `index.html` directly or visit the GitHub Pages link. Filter by category or search across shortcuts and descriptions. Click the copy icon to copy a key combo.
